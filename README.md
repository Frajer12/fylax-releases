FYLAX — Desktop Releases

Official distribution repository for FYLAX desktop installers (Windows 11 & macOS Apple Silicon).

Latest Download: Download Latest Release

1. Download & Installation
Windows 11 (x64)
Go to the Latest Release page.
Download FYLAX-Windows-11-Setup-<version>.exe.
Run the installer and follow the setup wizard.
If Windows SmartScreen appears: click More info → Run anyway.
macOS (Apple Silicon / arm64)
Go to the Latest Release page.
Download FYLAX-Mac-arm64-<version>.dmg (recommended) or FYLAX-Mac-arm64-<version>.zip.
Open the .dmg and drag FYLAX.app into your Applications folder.
First launch (unsigned build notice):
Right-click (or Control-click) FYLAX.app in Applications → Open → Open.
If macOS still blocks opening the app, open Terminal and run:
bash
xattr -cr /Applications/FYLAX.app
2. How to Create an Account
Launch FYLAX.
Choose one of the sign-up methods:
Email & Password: Enter your first name, email, and password, then confirm with the 6-digit OTP code sent to your inbox.
Continue with Google: Sign in with Google, set an account password during onboarding, and confirm with the 6-digit OTP code.
Every new account starts on the Demo plan so you can test audits right away (up to 3 findings shown per audit).
